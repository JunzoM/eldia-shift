# eldia-shift

HOTEL ELDIA シフト管理（PC内で動くローカル版）。

- Windows PC での設置・運用：[WINDOWS.md](WINDOWS.md)
- Mac で組んで Windows へ移す：[MAC.md](MAC.md)
- iPad から使う（事務所Wi-Fi）：[IPAD.md](IPAD.md)
- アバターメーカー：シフト表を起動中に http://127.0.0.1:8765/avatar を開く（顔・髪型・目・口・メガネ・帽子・服などを組み合わせて 3D アバターを作成し、PNG で保存。3D 表示は同梱の three.js を使うのでインターネット不要）
